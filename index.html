核心逻辑流

五个 Agent 分工协作，完成从采集到日报的闭环

01

采集 Agent

按订阅源、关键词和行业标签抓取新闻列表，记录来源、时间和原始链接。

02

解析 Agent

提取正文、清洗广告噪声、识别缺失字段，并把失败页面交给重试队列。

03

去重 Agent

按标题、正文语义和来源可信度合并重复报道，保留最高质量版本。

04

分析 Agent

判断主题、影响范围、可信度和优先级，输出结构化标签与评分。

05

写作 Agent

生成短摘要、深度解读和每日情报简报，供前台查看或导出。
